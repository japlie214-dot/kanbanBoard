# Kanban (Antigravity)
Track non-trivial work in the central Kanban board via MCP tools (`backlog -> build -> verify -> done`).
Read `project.md` and `epic.md` before planning.
Load the `kanban` skill when creating, retiring, or handing off tickets or posting Cases.
Hand off `verify` tickets to `kb-qa` (or human web approval) before committing.
