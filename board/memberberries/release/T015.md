## Outcome
Staged chunks get a short summary and an explicit_signal flag from the configured command-line model, and the summary (never the conversation text) is embedded with the configured embedding backend (EmbeddingGemma 2 in process, or a loopback server with a model id); both are stored with the chunk, tagged with the model identity, so the linking in T016 needs no further model call. Run by `memb curate` and the daemon (opt-in), never by a hook. LIMIT (stated plainly): summaries cover STAGED chunks only (the ones about to be curated), not every chunk ever made; the Phase 3 wording 'every chunk' is met going forward for chunks that reach staging.


## Scope
memb-scroll chunk schema and helpers, memb-curator summary prompt/parse and sandbox cwd (T018 A1), memb-rag embed_text, memb curate. Out of scope: linking and packets (T016), applying edits (T017).
