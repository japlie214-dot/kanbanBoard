## Outcome
The retrieval gate and dedup behave as Phase 1/2 specify: slash commands never trigger retrieval, a note updated after it was injected is injected again, the query cache works for one-shot hook processes (or is recorded as stdio-only), hook latency is measured, and the Phase 1 checklist cases are tests. Wiki/Phase-Coverage currently claims the slash skip; the code does not have it.


## Scope
memb-scroll gate and dedup, memb hook, memb-rag cache, tests.
