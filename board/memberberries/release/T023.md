## Outcome
Retrieval does not rebuild its index on every query: a persistent i8 working set with version invalidation, a wired document embedding cache with a stable key, indexed one-hop expansion, and prompt formats aligned with the Phase 2 spec. Today every search loads all notes and scans them, and cache_doc_embedding has no caller. Source: Phase 2 and shared plan section 4.


## Scope
crates/memb-rag, memb-embed, memb-store expansion.
