# A new strategy appears in the lab after adding one file; capital and costs are settable

## Outcome

Dropping one strategy file into `harness/strategies` makes it selectable in the lab with no other edit, a broken strategy file is named instead of hiding the others, and a run can set starting capital, commission and slippage.

## Why

Review 2026-11-12, finding F3: adding a strategy needs an edit to a hand-kept import list, a class-name convention nobody states, and the lab runs every strategy at a fixed 10,000 dollars with fixed costs. Boss, 2026-11-12: "an app where we can freely test any strategy easily".

## Requirements

1. Every module in `harness/strategies/` whose name does not start with `_` is imported automatically; no list to maintain.
2. A module that fails to import is recorded by name with a one-line reason and does not stop the others.
3. A strategy may state its config class explicitly; otherwise the existing name convention applies. A strategy with neither is reported, not fatal.
4. Starting capital, commission and slippage are per-run settings with today's values as defaults.
5. With defaults, results are identical to today's.
6. Every growth-of-1-dollar figure divides by the run's own starting capital.

## Design

**`harness/registry.py`**

```python
_LOAD_ERRORS: Dict[str, str] = {}

def _load_builtin_harnesses() -> None:
    # still lazy, same guard
    import importlib, pkgutil
    import harness.strategies as package
    for info in sorted(pkgutil.iter_modules(package.__path__), key=lambda m: m.name):
        if info.name.startswith("_") or info.ispkg:
            continue
        try:
            importlib.import_module(f"{package.__name__}.{info.name}")
        except Exception as exc:
            _LOAD_ERRORS[info.name] = f"{type(exc).__name__}: {str(exc).splitlines()[0][:200] if str(exc) else ''}"
```

**`replay_runner.py`**

- `_make_config` uses `config_type_for(harness_cls)`; the unknown-parameter error is unchanged.
- `ReplayConfig` gains `initial_capital: float = 10000.0`, `commission_bps: float = 1.0`, `slippage_bps: float = 4.0`. Lines 124-129 and 222 use them.
- `validate_run_settings(capital, commission_bps, slippage_bps)` raises `ValueError` with one sentence when capital is not a finite number in 100 to 1,000,000,000, or either cost is not finite in 0 to 500 basis points. Called at the top of `run_replay`.
- The tape gains top-level `initial_capital`, `commission_bps`, `slippage_bps`.

**`paths_runner.py`**: `PathsRequest` gains the same three fields, passed to `ReplayConfig`; `path_row` divides by `tape.get("initial_capital", 10000.0)`.

**`web/server.py`**

- `strategies()`: for each registered class, build the row inside `try`; use `config_type_for`. A class that fails goes to an errors map instead of raising. The response stays a list of rows (the page and tests read a list).
- New `GET /api/strategy-errors` → `{"modules": load_errors(), "strategies": {key: reason}}`.
- `ReplayRequest` and the paths request gain `initial_capital`, `commission_bps`, `slippage_bps` with the defaults; passed through. `ValueError` from validation is already a 400.
- Run summary: `final_growth = equity / tape["initial_capital"]`; summary stores the three settings.

**Page**: a collapsed "Run settings" group in the left column with three number inputs (capital, commission bps, slippage bps), prefilled with defaults, sent with single runs and many-path runs, and set from the opened run. Growth figures use `tape.initial_capital ?? 10000`. On load, fetch `/api/strategy-errors`; when either map is non-empty, show one dim line under the Strategy select: "N strategy files could not be loaded" with the names in its tooltip and listed on click.

Why this shape: discovery replaces one list with one loop and keeps laziness, so the import-cycle protection stays; the config lookup lives in one function instead of two copies; capital and costs travel in the tape, so every consumer reads them from the run instead of assuming.

## Ripple effects

- Discovery imports every module in the folder → a stray experiment file dropped there now loads and may register a strategy or fail → it is listed or reported by name; nothing else breaks. Files starting with `_` are skipped: that is the documented way to park a draft.
- Import order changes from the hand list to alphabetical → modules import their own dependencies, so order should not matter → proven by the registered-names comparison and the existing replay suite.
- Nightwatch parity test imports the same registry → run it (read-only, from the Nightwatch work root) and paste its tail.
- New tape keys → T002 summaries and T005 rows read them with a default for older tapes; older saved runs still open.
- Different capital changes absolute order sizes inside strategies with fixed-dollar floors → results at 100,000 are not 10x the results at 10,000. Expected; say so in the report, do not "fix" it.
- Costs at 0 are allowed → a run can look better than reality; the page shows the settings in the chart tag so a screenshot cannot hide them. Add them to the tag.
