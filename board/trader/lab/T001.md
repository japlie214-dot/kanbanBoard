# Lab server serves only its own replay files and listens on loopback only

## Outcome

A request to the lab web server can read only replay tapes and run reports the lab itself wrote, and the server is reachable only from this machine.

## Why

Review 2026-11-12, finding F2 (`scratch/review-2026-11-12/REPORT-1-etoro_trader.md`). Reproduced: a crafted replay id returned a `.json` file from outside the replay folder. First ticket of the lab redesign because every later ticket adds endpoints to the same file.

## Scope

- `repos/etoro_trader/web/server.py`
- `repos/etoro_trader/tests/test_web_server_paths.py` (new)

## Out of scope

The startup deletion of replays (T002). Any new endpoint. The page. `/api/data`, `/api/run` behaviour other than id checking. Authentication.

## Requirements

1. A tape id is accepted only if it fully matches `replay_` + 8 digits + `T` + 6 digits + `_` + 6 lowercase hex characters.
2. A run id is accepted only if it fully matches `run_` followed by 1 to 80 characters from `A-Z a-z 0-9 _`.
3. A rejected id returns HTTP 400 with detail `invalid tape id` or `invalid run id`. No file is opened.
4. After the pattern check, the resolved path must lie inside the resolved base folder; otherwise 400. (Second, independent guard.)
5. A well-formed id that does not exist still returns 404 as today.
6. The server binds `127.0.0.1` when started with `python web/server.py`.
7. No CORS middleware is installed.

## Design

All in `web/server.py`.

```python
import re

HOST = "127.0.0.1"
PORT = 8765
_TAPE_ID = re.compile(r"replay_\d{8}T\d{6}_[0-9a-f]{6}")
_RUN_ID = re.compile(r"run_[A-Za-z0-9_]{1,80}")


def _safe_child(base: Path, name: str, pattern: re.Pattern, what: str, suffix: str = "") -> Path:
    """Return base/name+suffix only for an id of the expected shape that stays inside base."""
    if not pattern.fullmatch(name):
        raise HTTPException(status_code=400, detail=f"invalid {what} id")
    path = (base / f"{name}{suffix}").resolve()
    if not path.is_relative_to(base.resolve()):
        raise HTTPException(status_code=400, detail=f"invalid {what} id")
    return path
```

- `get_replay`: `path = _safe_child(REPORTS_DIR / "replays", tape_id, _TAPE_ID, "tape", ".json")`, then the existing exists check and read.
- `get_run`: keep the in-memory lookup first, but run `_safe_child(REPORTS_DIR, run_id, _RUN_ID, "run")` **before** it, so a malformed id is refused in both branches. Use the returned path as `run_dir`.
- `get_run_report`, `get_run_trades`: `run_dir = _safe_child(REPORTS_DIR, run_id, _RUN_ID, "run")`, rest unchanged.
- Read `REPORTS_DIR` through the module global at call time (as today), so tests can replace `web.server.REPORTS_DIR`.
- Delete line 59 and the `CORSMiddleware` import at line 31.
- `uvicorn.run(app, host=HOST, port=PORT, log_level="info")`; the two printed URLs use `HOST` and `PORT` (`http://127.0.0.1:8765/`), not `localhost`, so the printed address is the one actually bound.
- `fullmatch` is required, not `match`, so no trailing characters pass.

Why this shape: one helper used by every file-serving route, so T002 and later tickets reuse it instead of repeating checks.

## Ripple effects

- CORS removed → any page on another origin calling this API stops working → none exists in the repository (`web/static/index.html` is the only caller, same origin) → proof: grep for `8765` and `/api/` outside `web/`.
- Host changed → the lab is no longer reachable from a phone or another PC on the network → intended; state it in the builder report so the PM can tell the Boss.
- `_RUN_ID` → run ids containing a hyphen or dot would now be refused → model and harness names in `/api/config` use only letters and underscores; report folders use `run_YYYYMMDDTHHMMSS_xxxxxx`. Builder confirms by listing `reports/` names against the pattern (read-only) and reports any that fail.
- Host changed → `.claude/launch.json` previews the lab at `localhost:8765` → on a machine where `localhost` resolves to IPv6 first, the client must fall back to IPv4; browsers do. Do not edit `launch.json` (out of scope); the PM checks the preview after the change.
- Nightwatch's parity test imports `harness` and `indicators` only → unaffected; not rerun.

## Watch

- **Tests must never touch the real `reports/` folder.** Entering `TestClient(app)` as a context manager runs `lifespan`, which deletes `REPORTS_DIR / "replays"`. Set `web.server.REPORTS_DIR` to `tmp_path` with `monkeypatch` **before** creating the client. Do not run the server from the owner's checkout to prove anything; use the tests, or a scratch copy.
- An HTTP client may normalise `..` in a URL. Keep the `%5C` (encoded backslash) form in the request tests, and also test `_safe_child` directly so the guard is proven without relying on client behaviour.
- `Path.is_relative_to` needs Python 3.9+; the machine runs 3.13.
- Do not "fix" the startup deletion here.
- Do not weaken the pattern to accept upper-case hex: tape ids come from `hexdigest()`, which is lower-case.
