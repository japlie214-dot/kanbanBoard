## Outcome
The Kanban Web App UI/UX is overhauled into a masterclass reactive dashboard featuring:
1. An interactive visual DAG graph component rendering execution lanes, branching decision diamonds (`[when:if/else]`), parallel tracks, and real-time node state colors (emerald for done, glowing pulsing border for `ready_nodes`, gold for mandatory acceptance, muted strikethrough for skipped).
2. Elimination of markdown spacing glitches and ticket body whitespace collapsing.
3. A resizable bottom inspector drawer preserving clear line of sight to all board columns, equipped with a persistent top-right close button, fullscreen expander, and multi-tab drawers (Visual DAG, Ticket Spec, Process Audit Stream, Touched Files, and Living Docs Reader).
4. Real-time telemetry with live agent lease countdown timers (`[⏱ 54m 22s]`), agent session pill tags, and instant SSE push updates falling back to debounced HTTP polling.
