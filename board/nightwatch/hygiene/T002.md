# T002 — Ignore and clear transient test-tmp directories in repo root

## Outcome
Transient pytest/agent tmp directories no longer sit in the repo root, and `.gitignore` ignores future ones.

## Why
Debris makes `git status` noisy before S3 commits a large tree; a mis-staged tmp dir could leak account data (`nightwatch.db` inside one).

## Context (observed 2026-09-25)
Not ignored by current `.gitignore`:
- empty: `.codex-agent-test-tmp`, `.p1-test-tmp`, `.pytest-basetemp-core-1`, `.pytest-basetemp-parser-debug-20260918`, `.pytest-basetemp-parser-p1-faildetails-20260918`, `.pytest-basetemp-parser-p1-full-20260918`, `.pytest-basetemp-repo-alone-3`, `.pytest-basetemp-repo-debug-4`, `.pytest-wrap-t5`, `.tp-probe-tests-20260918a`
- non-empty: `.pytest-run-authorized-t5/` (3 test dirs: two hold `data/nightwatch.db`, one holds `logs/log_2026-09-18.txt`; already shown ignored via `data/`/`logs/` rules)
Existing ignore block: `tmp*/`, `pytest-cache-files-*/` (does not match dot-prefixed names).

## Scope
`.gitignore` edit; delete the ten empty dirs.
## Out of scope
`.pytest-run-authorized-t5/` contents: do not delete; list file sizes only (PM decides). Any other path.

## Design
Add to the existing "Transient pytest tmpdir" block of `.gitignore`:
```
.pytest-basetemp-*/
.pytest-run-*/
.pytest-wrap-*/
.p1-test-tmp/
.tp-probe-tests-*/
.codex-agent-test-tmp/
```
Delete empty dirs with `rmdir` (fails if non-empty = safe).
