# Demo-only tool to open manual SCHG positions

## Outcome

The operator can open N SCHG market buys on the DEMO account from the phone, to create manual positions for the T068 adoption test.

## Scope

new android-probe/app/src/main/python/probe/demo_manual_buy.py, MainActivity.kt button, tests.

## Acceptance

Refuses unless config environment=demo AND gate-7 style environment detection says demo; real is refused in code (test). Operator-only: MainActivity button + confirm dialog (count and USD each), never from session/alarm/command. Caps: 1-10 positions, 50-15000 USD each. Uses the EtoroClient demo write path; prints each order result redacted; writes NO lot_annotations and NO session intents (positions must stay unmanaged). Device proof: Boss-approved run of 5 x ~11000 USD SCHG; positions visible in demo portfolio.

## Prove

Both pytest suites green; Gradle unit tests; git diff --check; device proof as in acceptance.

## Design
Runner probe/demo_manual_buy.py run(home, count, usd_each): explicit set_host(DesktopHost(home)) (T067 pattern). load_config: refuse unless etoro.environment == demo; build the write-role client; detect the environment against the demo portfolio (reuse gate 7 helper) and refuse on mismatch; resolve the SCHG instrument; loop count times calling place_buy_order(SCHG, usd_each) sequentially; stop on the first error; print redacted results (T060/T065 formatters). No DB writes. Kotlin: a "Open demo SCHG positions" button with two number fields and a confirm dialog repeating the totals; runs on a background thread; the result is shown in a TextView.
