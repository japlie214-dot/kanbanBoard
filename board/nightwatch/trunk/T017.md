# T017 — S6c-2: every session that reaches the arm gate writes one portfolio snapshot taken from a single `/pnl` read, covering every position with the broker's own marks

## Outcome
After T016's decision row, `run_session` makes one `client.get_pnl()` call and inserts one `PortfolioSnapshot` (one row in `portfolio_snapshots`, one row per position in `portfolio_snapshot_positions`). Each position is marked by the broker (`unrealizedPnL.closeRate`, `unrealizedPnL.pnL`). The raw envelope plus our provenance go into `raw_json`. A snapshot failure never changes the session status: it is reported in the outcome.

## Why
- project.md S6 design call: an unarmed run still writes the snapshot, because it is read-only data.
- T010 (daily loss report and alert) needs consecutive comparable snapshots. Evidence not captured at the time cannot be recovered later.
- Consultant (2026-10-07): capture now, keep the extra evidence in versioned `raw_json`, and add no speculative columns.

## Design (PM decisions)
1. One `/pnl` call is the only source. It is one envelope, so cash, positions and marks are mutually consistent, and every instrument is marked by the broker. Rejected alternatives:
   - marking with our own prices covers only the 3 managed symbols, and rates go stale (DESIGN_market_data);
   - `get_portfolio` plus `get_balance` means separate, non-atomic reads.
2. `build_snapshot(*, session_id: int, taken_at: str, pnl: Mapping, available_cash: float | None, symbol_by_instrument: Mapping[int, str], session_prices: Mapping[str, float], sleeve: Mapping[str, float]) -> PortfolioSnapshot`. It is pure.
   - `cp = pnl["clientPortfolio"]`. A missing key raises `SnapshotError`.
   - For each position `p` in `cp["positions"]`, `u = p.get("unrealizedPnL") or {}`. Build `SnapshotPosition(position_id=str(p["positionID"]), instrument_id=p.get("instrumentID"), symbol=symbol_by_instrument.get(p.get("instrumentID")), units=p.get("units"), entry_price=p.get("openRate"), current_price=u.get("closeRate"), amount=p.get("amount"), leverage=p.get("leverage"), unrealized_pnl=u.get("pnL"), open_date=p.get("openDateTime"))`.
   - `missing` = the position ids where `closeRate` or `pnL` is None, or `amount` is None.
   - `complete = not missing and cp.get("accountCurrencyId") == 1`.
   - `cash = cp["credit"]`. `unrealized_pnl = cp.get("unrealizedPnL")`. `realized_pnl = None`, because no source exists yet.
   - `equity = cash + sum(amount + pnL)` over the positions **only if `complete`**, else `None`. Never publish a partial sum as equity.
   - `available_cash` = the argument, taken from T016's `balance.available_cash`.
   - `raw` = `{"version": 1, "phase": "post_decision", "source": "pnl", "complete": complete, "missing": missing, "account_currency_id": cp.get("accountCurrencyId"), "managed_instrument_ids": sorted(symbol_by_instrument), "sleeve": dict(sleeve), "mark_check": mark_check, "pnl": pnl}`.
   - `sleeve` = `{"cash_reserve_usd", "sleeve_cash", "sleeve_equity", "schg_position_value"}`, taken from T016's inputs and config. It records what the app saw.
   - `mark_check` = for each managed symbol with a position: `{"symbol": s, "session_price": session_prices[s], "broker_close_rate": the closeRate of the first position of that instrument, "diff_pct": round(100 * (broker - session) / session, 3)}`. It is evidence only, never a failure. **PM fix 2026-10-08:** use `price = session_prices.get(s)`; if `broker` or `price` is None (or price == 0), store the entry with `"diff_pct": None`. Never raise from mark_check. Test: a position missing `closeRate` gives `complete` False, its mark_check entry has `diff_pct` None, and no exception.
   - Credentials: the `/pnl` body has no credentials. Store it as-is. Add no headers.
3. In `run_session`, after `insert_decision`:
   - `try`: `pnl = client.get_pnl()`, `snap = build_snapshot(...)`, `sid = repo.insert_snapshot(snap)`, then append `f"; snapshot {sid}: {len(snap.positions)} position(s), equity={snap.equity}, complete={snap.raw['complete']}"`.
   - `except Exception as e`: append `f"; snapshot failed: {type(e).__name__}: {e}"`.
   - The status stays `would_have_done` either way. A snapshot is report data, not a gate.
   - `taken_at = utcnow()`, the same helper session.py already uses.
4. Why this shape: `build_snapshot` is pure, so it is tested on the fixture. T010 later reads `raw` without a migration, because it is versioned JSON.
