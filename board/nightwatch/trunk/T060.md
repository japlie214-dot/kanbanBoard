# T060: Redact device diagnostics (audit G15)

## Outcome
No FCM payload, registration token, raw event detail or raw broker response body reaches logcat or the snapshot push.

## Why
FCM handler logs full data and tokens (NightwatchProbeMessagingService.kt:71-75, 139-145); SnapshotPusher sends recent event details unredacted (SnapshotPusher.kt:52-70); client fallback prints unrecognized write bodies (client.py:1448-1452).

## Context
Context cites readiness audit 2026-11-06 at HEAD 21c06ba (project.md). Builder re-verifies every line before editing. Do not touch android_entry.py, Kotlin or doc/ (T054 in flight). This ticket edits Kotlin files that T054 does NOT touch; build after T054 lands to keep one Gradle build line.

## Scope
NightwatchProbeMessagingService.kt, SnapshotPusher.kt, app/src/main/python/nightwatch/etoro/client.py (fallback log only), JVM tests, tests/test_etoro_client.py.

## Out of scope
Secret storage design (G03).

## Design
Kotlin: log only message type and key names; token logged as length+last4 hash. Snapshot: allowlist fields (event type, timestamp, fixed labels) and pass detail through the Python T048 redactor via PyBridge before push. Client: log status + byte length, not body.

## Plan
client log → Kotlin logging → snapshot allowlist → tests → Gradle + both suites.

## Acceptance
1. JVM test: FCM handler log lines contain no data values or token.
2. Snapshot payload contains only allowlisted keys; secret-looking strings redacted.
3. Client fallback log has no body.
4. Gradle tests + both suites pass.

## Prove
android-probe gradlew :app:testDebugUnitTest :app:assembleDebug (online allowed); both pytest suites.

## Dependencies
T054.

## Done when
QA observes acceptance.

## Amendments after precheck (2026-11-06; latest wins)
- Scope paths are under `app/src/main/python/nightwatch/` (etoro/client.py).
- Kotlin edits are allowed except in T054-owned files until T054 is committed. After T054 is committed, `android-probe/app/src/main/java/com/nightwatch/etoro/probe/PyBridge.kt` is in scope for a redaction bridge to the T048 redactor (with config and a safe fallback). Build after T054.
- Token hash format: length plus the first 8 hex characters of SHA-256 of the token. Never token characters.
- Snapshot allowlist fields: session date, status, outcome label, halt flag, next run time, check name, check pass/fail, and check details (redacted). Event details are redacted. Fail closed: when redaction is unavailable, omit details entirely.
- Also cover body-bearing exceptions at client.py:1460-1475 (no raw response body in exception text) and the latency probe printing at `android-probe/app/src/main/python/probe_order_latency_2026_09_11.py:474-489`; add both to scope.
- EventStore SQLite (EventStore.kt:60-68) is a sink too: FCM data and tokens are stored redacted. Acceptance covers logcat and the event store.
