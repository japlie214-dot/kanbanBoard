# T015 — S6b: the session fetches market data, wires gate 10 at preflight and again after the T-30 wait, and assembles the SPY signal

## Outcome
A dry run gets past all 12 gates. It then:
1. waits until T-30, or skips the wait with `--no-wait`;
2. re-fetches the market data;
3. reruns gate 10 on the fresh data;
4. assembles the SPY signal: `cone_5_z`, drawdown and tier.

It ends with status `signal_ready`, the session `finished`, and an outcome line summarising the signal. Decide/report/snapshot are S6c.

## Requirements
1. `MarketInputs`, a frozen dataclass:
   - `iex: dict[str, IexQuote | None]`;
   - `rates: dict[str, Rate]`;
   - `candles: dict[str, Candle | None]`, the latest daily candle;
   - `provisional_closes: dict[str, ProvisionalClose]`;
   - `instrument_ids: dict[str, int]`.
2. `fetch_market_inputs(*, tiingo: TiingoClient, client: EtoroClient, symbols: Sequence[str]) -> MarketInputs`:
   1. `ids = {s: client.resolve_instrument_id(s)}`.
   2. `rates_by_id = client.get_rates(list(ids.values()))`, then re-key by symbol.
   3. For each symbol: `candle = (client.get_candles(ids[s], count=1) or [None])[-1]`. With `count=1` the list has one element, `[0]` (direction backward = desc, client.py:1126–1151).
   4. IEX: `try: q = tiingo.get_iex_quotes(list(symbols)) except Exception: q = {}` (log a warning). IEX unreachable → candle fallback, per `resolve_provisional_close`.
   5. `provisional_closes[s] = resolve_provisional_close(s, iex_quote=q.get(s), etoro_daily_candle=candle)`. It raises `WindowAssemblyError` when both the quote and the candle are absent (window.py:440–448). Catch that per symbol, leave `s` out of `provisional_closes`, and record `f"{s}: {exc}"` in a new `MarketInputs.errors: dict[str, str]` field.

   A missing rate or candle leaves that key absent or `None`. eToro errors propagate.
3. Gate 10 in `build_preflight_gates`: a closure that runs `mi = fetch_market_inputs(tiingo=tiingo, client=client, symbols=config.symbols.all)`. If `mi.errors` is non-empty, it returns `GateResult(10, "price_data", False, "no provisional close: " + "; ".join(mi.errors.values()), {"errors": mi.errors})`. Otherwise it returns `gate_10_price_data(now=now(), managed_symbols=config.symbols.all, provisional_closes=mi.provisional_closes, rates=mi.rates, candles={k: v for k, v in mi.candles.items() if v is not None}, config=config.market_data)`. `build_preflight_gates` gains the parameter `tiingo: TiingoClient`.
4. `run_session` gains the parameters `tiingo: TiingoClient`, `wait: bool = True`, and `sleep_until: Callable[[datetime], None] = _sleep_until`. `_sleep_until` sleeps in ≤ 60 s chunks until `host.now() >= target`. After preflight passes:
   1. `t30 = session_close_datetime(trading_date) - timedelta(minutes=30)`. If `wait` and `host.now() < t30` → `sleep_until(t30)`.
   2. `mi = fetch_market_inputs(...)`. `g = gate_10_price_data(...)` as above, with `now=host.now()`.
   3. If `g` fails → `finish_session(id, state="aborted", outcome=f"gate 10 rerun: {g.reason}")`, then return `SessionResult(id, "rerun_failed", 10, reason)`. The rerun is NOT written to `preflight_checks`, because that would overwrite the preflight row. It goes in the session outcome.
   4. `athes = [a.entry_spy_ath for a in repo.list_lot_annotations(is_open=True) if a.entry_spy_ath is not None]`. That is all open lots, both books and both symbols (window.py:593–606).
   5. `sig = assemble_spy_signal(tiingo, trading_date=iso, iex_quote=mi.iex.get("SPY"), etoro_daily_candle=mi.candles.get("SPY"), cone_horizon=config.strategy.cone_horizon, open_lot_entry_spy_ath=athes)`. If it raises → abort the session with `outcome=f"signal: {type(e).__name__}: {e}"` → return `signal_failed`.
   6. `fp = sig.fingerprint; repo.record_price_window_fingerprint(PriceWindowFingerprint(trading_date=fp.trading_date, symbol=fp.symbol, window_start=fp.window_start, window_end=fp.window_end, bar_count=fp.bar_count, series_sha256=fp.series_sha256, source=fp.source, source_fetched_at=fp.source_fetched_at))`. The fields match (window.py:187–204, repo.py:345–363).
   7. `finish_session(id, state="finished", outcome=f"dry run: cone_5_z={sig.cone_5_z}, drawdown={sig.spy_context.drawdown}, tier={sig.spy_context.tier}; decide not built (S6c)")` → return `SessionResult(id, "signal_ready", None, outcome)`.
5. CLI: build `TiingoClient(config.tiingo)` and pass it, and close it if it has `close()`. Add `--no-wait` (passes `wait=False`). Exit 0 for `signal_ready`.

## Design
- Gate 10 stays a pure function. The session owns fetching (preflight.py:858–866 says the session decides how to obtain the data).
- The rerun is authoritative and is kept out of `preflight_checks`, because the upsert key `(session_id, gate)` would erase the audit of the first pass.
- `--no-wait` (new flag) lets a dev run during market hours need not wait. The default waits, as production does.
