# T016 — S6c-1: the dry run calls `decide` on inputs built from live broker data, persists the phase A decision, and stops at the arm gate with a "would have done X" outcome that names every reason arming is refused

## Outcome
After the SPY signal (T015), `run_session` does the following:
1. Reads the broker portfolio and balance.
2. Builds `LadderInputs` from the same session's prices.
3. Calls `strategy.ladder.decide`.
4. Persists one `decisions` row.
5. Evaluates the arm gate.

The session finishes with status `would_have_done`. Its outcome line lists every intent and every reason arming is refused. Strategy state is NOT advanced.

## Why
project.md §6 S6, step 4 (S6c). DESIGN_session.md §5 [6a] and [7a]: when the session is not armed, it reports "would have done X" using phase A's full decision and stops cleanly. project.md §11: the dry run must name the arming-refused reasons visibly. A silent "not armed" is not acceptable.

## Design (PM decisions)
1. `build_ladder_inputs(*, iso: str, year: int, signal: AssembledSignal, prices: Mapping[str, float], positions: Sequence[Position], symbol_by_instrument: Mapping[int, str], balance: Balance, repo: Repo, cash_reserve_usd: float) -> tuple[LadderInputs, list[str]]`. It is pure apart from repo reads. The second item is a list of human-readable input notes.
   - `prices = {s: mi.provisional_closes[s].value for s in mi.provisional_closes}`. `upro_price = prices["UPRO"]`, `schg_price = prices["SCHG"]`.
   - `symbol_by_instrument = {v: k for k, v in mi.instrument_ids.items()}`. Positions in instruments outside this map are ignored, with the note `"{n} position(s) in unmanaged instruments ignored"`.
   - Only `is_buy` positions count. A non-buy position → note `"ignored short position {id}"`.
   - `cash = max(0.0, balance.available_cash - cash_reserve_usd)`.
   - `schg_position_value` = the sum of `units * schg_price` over **all** SCHG positions. SCHG is the core sleeve and is not lot-tracked.
   - `open_lots` comes from the open annotations with `symbol == "UPRO"`, joined to broker positions by `position_id`. Each lot is `LadderLot(symbol="UPRO", book=a.book, units=p.units, entry_price=p.entry_price, cost_basis=p.amount, entry_date=a.entry_date, entry_reference_spy=a.entry_reference_spy, entry_spy_ath=a.entry_spy_ath, entry_spy_close=a.entry_spy_close, entry_spy_drawdown=a.entry_spy_drawdown, entry_tier=a.entry_tier, bucket_id=a.bucket_id, position_ref=a.position_id)`.
   - If an annotation has `entry_reference_spy is None`, or its position is missing at the broker, raise `DecideInputError` naming the position_id. Fail closed: no reconciliation guessing here.
   - UPRO broker positions with no open annotation are excluded from `open_lots` and from equity. Note: `"{n} UPRO position(s) not annotated (adoption is S4): excluded from lots and equity"`.
   - `equity = cash + sum(lot.units * upro_price for lot in open_lots) + schg_position_value`.
   - `buckets`: map `repo.active_buckets()` to `ReentryBucket`. If `last_reference_spy is None`, raise `DecideInputError(f"bucket {id} has no last_reference_spy")`.
   - `StrategyConfig.budget_override_usd` (config.py:262) is not mapped by `LadderConfig`. **This check lives in `run_session`, not in `build_ladder_inputs`** (the builder signature stays as written): after `build_ladder_inputs` returns `notes`, if `config.strategy.budget_override_usd is not None`, append `"budget_override_usd set but not honoured (ladder has no field)"` to `notes` before they go into the reason. Do not change ladder.py. Test it in `tests/test_session_decide.py` (override set gives the note; None gives no note).
   - `prior_year_schg_values = (m,)` if `repo.mean_schg_value(year - 1)` returns a float `m`, else `()` with the note `"no prior-year SCHG values"`. A singleton mean is enough, because `_ensure_budget` only takes the mean.
2. `arming_refusals(config: Config) -> list[str]`, in this order:
   - `f"mode is {config.mode.value}, not live"` if not LIVE;
   - `"NIGHTWATCH_ARM not set"` if `not config.arm_flag_present`;
   - `f"risk limits unset: {', '.join(names)}"` for the fields among `max_notional_per_session_usd`, `max_daily_loss_usd` and `max_open_lots` whose value is `None`.

   Precheck: confirm that `config.mode` has `.value` and that the attribute name is `arm_flag_present`.
3. `intent_to_dict(i: LadderIntent) -> dict` returns `{"symbol", "side", "amount", "position_ref", "reason", "book"}`, using the ladder's own vocabulary with no translation to buy/sell.
4. In `run_session`, after the fingerprint:
   1. `positions = client.get_portfolio()`, then `balance = client.get_balance()`. Any exception → `finish_session(state="aborted", outcome=f"decide inputs: {type(e).__name__}: {e}")` → `SessionResult(s.id, "decide_failed", None, outcome)`.
   2. `inputs, notes = build_ladder_inputs(...)`. `DecideInputError` → same abort, `decide_failed`.
   3. `state = strategy.state.load(repo)`, then `d = decide(inputs, state, LadderConfig.from_strategy_config(config.strategy))`. An exception → same abort, `decide_failed`.
   4. `repo.insert_decision(Decision(session_id=s.id, trading_date=iso, intents=[intent_to_dict(i) for i in d.intents], cone_z=inputs.cone_z, spy_close=inputs.spy.close, spy_ath=inputs.spy.ath, drawdown=inputs.spy.drawdown, tier=inputs.spy.tier, budget=d.new_state.budget, order_size=d.new_state.order_size, cash_target=d.new_state.cash_target, equity=inputs.equity, cash=inputs.cash, reason="phase A, pre-settlement, buy intents provisional; dry run: " + d.reason))`. There is no phase column, so the phase lives in `reason`, per DESIGN_session §5 [6a] wording.
   5. **Never** call `strategy.state.save`. The dry run must not advance bars, ATH, budget or streak.
   6. Build the outcome:

      `f"would have done {len(d.intents)} intent(s): {summary}; ladder: {d.reason}; arming refused: {'; '.join(refusals)}"`

      - `summary` = `"; ".join(f"{i.side} {i.symbol} ${i.amount:.2f}" if i.amount is not None else f"{i.side} {i.symbol} lot {i.position_ref}" for i in d.intents)`, or `"none"` when there are no intents.
      - If `notes` is non-empty, append `f"; inputs: {'; '.join(notes)}"`.
      - If `d.warnings` is non-empty, append `f"; warnings: {'; '.join(d.warnings)}"`.

      `finish_session(s.id, state="finished", outcome=...)`, then return `SessionResult(s.id, "would_have_done", None, outcome)`.
5. Why this shape: input building is a separate function, testable without a session, and T017 (the snapshot) reuses the same marks. The arm gate is a function, so S7 replaces the stop without touching decide.
