# T031 — On the real account, `clear_take_profit` sends `PATCH /api/v2/trading/positions/{positionId}` instead of refusing

## Outcome
`EtoroClient.clear_take_profit` no longer raises "real-account path unconfirmed (T012)" in REAL environment. It sends the same `{"clearTakeProfit": true}` body to `/api/v2/trading/positions/{id}` (no `demo/` segment). Everything else is unchanged: validation, ack parsing, no retry.

## Why
- project.md "Real-account TP path confirmed 2026-10-16": eToro docs, read after the Boss enabled DoH, give real = `PATCH /api/v2/trading/positions/{positionId}` and demo = `PATCH /api/v2/trading/demo/positions/{positionId}`, with the same options (`clearTakeProfit`/`clearStopLoss`), asynchronous. S7-5 = lift the refusal, test offline, prove live only with a Boss go.
- Real hand-placed positions carry a TP at about 11x (project.md §0, T6). Without this, a real buy leaves its TP in place and the session HALTs (T028/T030).

## Context
- `app/src/main/python/nightwatch/etoro/client.py:1512-1553`. The refusal is at :1523-1524; the URL is `f"/api/v2/trading/{self._demo()}positions/{position_id}"` (:1527), and `_demo()` (:384) returns `""` for REAL. So deleting the refusal gives the documented real URL.
- Tests `tests/test_etoro_client.py:274-360`. `test_clear_take_profit_real_mode_never_sends` (:337) asserts the refusal.

## Scope
`client.py` (delete the refusal, update the docstring "demo position" → "position", note both paths); `tests/test_etoro_client.py` (replace the :337 test).

## Out of scope

## Design
1. Delete lines 1523-1524. Docstring: "Remove a position's broker take-profit with one PATCH (demo: /demo/positions, real: /positions; eToro docs 2026-10-16)."
2. Replace the :337 test with `test_clear_take_profit_real_mode_sends_real_patch`, using the same REAL config. Script one 200 response with `{"operationId": "op-1", "positionId": "3550406905"}`. Assert:
   - exactly one request;

   - URL path exactly `/api/v2/trading/positions/3550406905` (no `demo`);
   - JSON body `{"clearTakeProfit": true}`;
   - `x-request-id` == `request-1`;
