## Context (read 2026-09-25, repo `repos/etoroNightwatch`)
- `app/src/main/python/nightwatch/etoro/client.py` about lines 985-1012 (`search_instrument` path): reads `data.get("items", data.get("instruments"))`, keeps only rows with `row["internalSymbolFull"] == symbol`, else raises `EtoroValidationError("no exact instrument found for symbol 'SPY'")`. `"items"` is the live key. This exact filter is intended (blocks `SPY.RTH` / `SPYD` contamination). **Do not change the client.**

  No `internalSymbolFull`, so every seed/settle test dies at the first HTTP call. Call sites: lines 118, 135, 146, 157, 179, 207, 483, 528, 554, 595, 619, 643. The file uses both `symbol="SPY"` (18) and `symbol="UPRO"` (4).

## Design
```python
def _search_response(instrument_id: int = 1001, symbol: str = "SPY") -> httpx.Response:
    return httpx.Response(
        200,
        json={"items": [{"instrumentId": instrument_id, "internalSymbolFull": symbol}]},
    )
```
At each call site whose test searches a symbol other than SPY, pass `symbol=` with that symbol. Why: the fixture must echo the queried symbol like the live API; a SPY row answering a UPRO search would hide a real mismatch.

## Plan
