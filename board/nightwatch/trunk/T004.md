# T004 — S5b: gate 1 halt switch fails preflight when the HALT flag exists

## Outcome
`gate_1_halt(host)` returns a failed `GateResult` while the HALT flag file exists, and a passed one otherwise. The operator's `nightwatch halt` command therefore stops every session at preflight.

## Why
Smallest real gate (project.md §6 S5). The halt command already writes the flag (`cli.py` `set_halt`, line 114), but nothing reads it yet.

## Context (PM read 2026-10-01; package root `app/src/main/python/nightwatch/`, P below)
- `P/host.py:76`: `Host.halt_flag_path(self) -> Path`, docstring "checked by preflight gate 1". `DesktopHost` implements it at line 119.
- `P/cli.py:114` `set_halt(host) -> Path` writes the file; line 126 `clear_halt(host) -> bool` removes it.
- `P/engine/preflight.py`:
  - `GateResult(gate, name, passed, reason, details={})` at about line 184.
  - `run_preflight(gates, *, repo, session_id)` and `unimplemented_gate` (T003, commit 130afd7).
  - Lines 25–35 say "The other ten gates remain comment-only stubs" and list gate 1 in a TODO.
- DESIGN §5 gate 1: the HALT flag is set (a file in app storage, or set via Telegram `/halt`). Telegram `/halt` also calls `set_halt`, so the file is the only signal.

## Scope
- `P/engine/preflight.py`.
- A new test file, `tests/test_preflight_gate_1.py`.

## Out of scope
- Other gates, the CLI, the host, the session and Telegram.

## Design
```python
def gate_1_halt(host: Host) -> GateResult:
```
- `path = host.halt_flag_path()`.
- If `path.exists()`: return `GateResult(1, "Halt switch", False, f"HALT flag present: {path}", {"path": str(path)})`.
- Otherwise: return `GateResult(1, "Halt switch", True, "no HALT flag", {"path": str(path)})`.
- Do not catch exceptions. `run_preflight` turns them into a fail-closed result.
- Import `Host` from `..host`, under `TYPE_CHECKING` if a normal import causes a cycle.
- Add `"gate_1_halt"` to `__all__`.
- Stale comments: in the docstring around lines 25–30, change "The other ten gates remain comment-only stubs" to "Gates 1, 10 and 11 are built; the other nine remain comment-only stubs". Change any text saying `run_preflight` does not exist so it says that `run_preflight` exists. Do not touch `session.py`.
