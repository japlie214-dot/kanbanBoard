# T023 — The cash withheld from NIGHTWATCH is set per eToro environment: demo $5,000, real $10

## Outcome
`config.toml` sets `cash_reserve_usd = { demo = 5000.0, real = 10.0 }`. At load time, `StrategyConfig.cash_reserve_usd` is resolved to the single float for the configured `etoro.environment`. Every consumer keeps reading one float and is unchanged. A plain scalar (the legacy form) still works and applies to both environments.

## Why
- 2026-10-09 live demo: `cash_reserve_usd = 0.0`, so the ladder treated all $100,001 of demo cash as sleeve and decided 136 × SCHG $666.66 (project.md §8).
- **The boss controls NIGHTWATCH's money by exclusion** (`cash_reserve_usd`, DESIGN §4.5). Boss 2026-10-10: demo excludes **$5,000** (so the exclusion is visible in a run), real excludes **$10**.
- The budget logic is unchanged: "follow the strat and buy the required SCHG", with or without SCHG history.

## Design
1. The TOML `strategy.cash_reserve_usd` accepts:
   - absent, `None` or `""`: `0.0` (unchanged);
   - a number: that number, for both environments (unchanged);
   - **a table** `{demo = <num>, real = <num>}`: take `table[environment.value]`. If the key for the active environment is missing, raise `ConfigError("strategy.cash_reserve_usd has no value for environment '<env>'")`. Fail closed, never default to 0, because 0 would mean "use all cash". Unknown extra keys raise `ConfigError` naming them.
2. The resolved float goes into `StrategyConfig.cash_reserve_usd`. The negative check (`:315`) is unchanged.
3. `config.toml`: replace `cash_reserve_usd = 0.0` with `cash_reserve_usd = { demo = 5000.0, real = 10.0 }`. Rewrite the comment's "CLOSED, 2026-09-05" paragraph to: "2026-10-10 boss decision: demo withholds $5000 (to make the exclusion visible in demo runs), real withholds $10. Per-environment table; a missing key for the active environment is a config error." Keep the rest of the explanation.
4. Why this shape: one resolved float means zero consumer changes, the legacy scalar stays valid, and a missing value fails closed.
