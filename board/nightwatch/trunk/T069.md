# Strategy state must advance even when the final save is vetoed

## Outcome

ath, bars, below_streak and bucket lifecycle advance every session that reached a decision, so a vetoed save can't make every later day look like a new ATH or freeze bucket expiry.

## Scope

engine/session.py, strategy/ladder.py, strategy/state.py, db/repo.py, tests.

## Acceptance

Audit S1/S3/S4/S5: session.py:871-907 saves strategy_state only when nothing was dropped/deferred/blocked; ladder.py:804 new_ath_bar = ath > state.ath then stays true daily after a real ATH, repeating SCHG cash-to-core sweeps; buckets never expire (ladder.py:718) and expired buckets stay active (session.py:904-906). Prove the bug first with a two-session scratch run, then split state into 'market facts' (ath, bars, streak, bucket expiry: always saved) and 'money effects' (recyclable cash, budget: saved only on full success), or an equivalent design reviewed by PM.

## Prove

Both pytest suites green; git diff --check clean; QA observes acceptance; device proof where the ticket says so.

## Design
Split persisted strategy state into market facts (always saved once decide() ran: ath, bars, below_streak, bucket expiry/deactivation) and money effects (recyclable_cash, budget/budget_year, sale batch counters, bucket fills: saved only on full success, today's veto). Builder must justify each field's class in the report; PM reviews.

## Plan
1. Reproduce S1 with a two-session offline test (stop with evidence if it does not reproduce).
2. Add the market-facts save on the veto branch (session.py:871-907), bucket deactivation included.
3. Tests: veto then non-ATH day produces no second sweep; buckets expire under repeated vetoes; money effects still not saved on veto.

## PM decision 2026-11-09 (re-QA)
Re-QA found: if the full strategy-state save raises before any order (`aborted_before_orders`), market facts stay unadvanced. Accepted as correct, not a defect: no order was sent, so this is equivalent to a crash before send; the next session re-derives any owed sweep from real cash. Advancing ATH here would reintroduce the lost-sweep bug. Repeated sweeps cannot result: a DB that rejects writes aborts every session before orders. Crash-retry ($859.72 / $759.72), veto-advance, money isolation and dry-run invariance passed on both interpreters (217 focused).
