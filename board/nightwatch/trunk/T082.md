# Deliver strategy rule fixes with matching dashboard monitoring

## Outcome

Close confirmed gaps against the pinned strategy and make every implemented trading rule and safety gate visually monitorable on the cloud dashboard, in paired implementation and evidence slices.

## Scope

Prepare and precheck paired rule-fix, durable evaluation evidence, allowlisted export and dashboard slices. Cover strategy sections 1 through 13 and twelve preflight gates. No device changes, orders, cloud deployment, fund allocation or secret access under this intake.

## Acceptance

For every rule show actual evaluated inputs, configured threshold or limit, evaluated verdict and reason, affected session and timestamp, and intended versus confirmed action. Distinguish pass, fail, not applicable, not evaluated, not implemented and unknown or stale; never infer pass from no trade or empty fields. Each rule fix must pass boundary tests and a dashboard reproduction of the same decision. Source coverage and missing proof remain explicit.

## Prove

Create a source-and-test-backed rule coverage matrix; independently verify paired engine decisions and rendered dashboard values on synthetic seeded scenarios, including blocked, skipped, failure and stale-data cases. Full same-engine forward acceptance remains required before strategy-complete claims.
