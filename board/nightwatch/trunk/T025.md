# T025 — On a first run (no saved ATH), the ladder seeds the ATH and does not treat the bar as a new all-time high

## Outcome
`decide()` with `state.ath is None` sets `new_ath_bar = False`, so there is no "cash to core" SCHG sweep. It stores the current `ath` in the new state as usual. From the second run on, a new ATH is detected exactly as today.

## Why
- The boss asked why the demo wanted 136 × SCHG $666.66 when SCHG is bought only on a new SPY ATH.
- Cause, PM read 2026-10-10:
  - `P/strategy/ladder.py:800` `new_ath_bar = ath > (state.ath or 0.0) + _EPS`;
  - `state.ath` is None on a fresh DB, so it compares against 0 and is always True;
  - `:909–917`: `if new_ath_bar:` `available = max(0.0, inputs.cash - cash_target - tier1_reserve)` (`:910`) → `_schg_buy_intents(amount, order_size)` ("cash to core").
  - On the 2026-10-09 demo (fresh temp DB, $100k cash) this produced about $90.7k of SCHG intents.
- The first live session on the real account would do the same with its sleeve cash.

## Context
- `ladder.py:792–808`: budget, `ath = inputs.spy.ath`, `new_ath_bar`, `base_state = LadderState(bars=..., ath=ath, ...)`.
- `new_ath_bar` is also reported in `diagnostics` (`:819`, `:888`).
- Other uses of `new_ath_bar` or `state.ath`: precheck greps the whole module (e.g. the `new_ath_sale` logic at `:678` uses `lot.entry_spy_ath or ath`, which is unrelated).
- State persistence: `strategy/state.py` load/save; the dry run never saves (T016).

Do not weaken its assertions.

## Out of scope
- Seeding the ATH from history elsewhere (the bootstrap, S7-4).
- Any other ladder rule.

## Design
- `new_ath_bar = state.ath is not None and ath > state.ath + _EPS`.
- Comment: "First run (no saved ATH): seed only. Comparing against 0 would count every first bar as a new ATH and sweep spare cash into SCHG (T025, 2026-10-09 demo)."
- Everything else is unchanged; `base_state.ath = ath` already seeds it.
- **Why:** this is the smallest change that matches the strategy's intent: SCHG is bought on a *new* high relative to a known previous high.
