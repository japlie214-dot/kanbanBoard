# T010 — A pure calculator turns two snapshots into the interval result for UPRO + SCHG: P&L in $ and %, the market-unexplained residual, a state, and the alert A / alert C verdicts

## Outcome
`compute_interval(prev, cur, ...) -> IntervalResult` is a pure, fully tested function in a new module. It takes the previous and the current `PortfolioSnapshot`, plus optional closed-trade history rows and independent marks. It returns:
- `pnl_usd` and `pnl_pct` for all UPRO and SCHG positions;
- `explained_usd` (the market) and `residual_usd` (P&L not explained by the market);
- one state out of `no_baseline`, `complete` and `incomplete`, with human-readable reasons;
- two booleans: `alert_a` (P&L ≤ −$500) and `alert_c` (residual ≤ −$50, only when complete).

It has no I/O, no config and no session code: T022 wires it in.

## Why
- The boss wants a loud alert on a big red day (A), and a HALT when a loss is not explained by the market (C), to catch the app, not the market.
- This module is the only place the money arithmetic lives. Keeping it pure makes every formula testable on synthetic cases before any of it can stop trading.

## Binding decisions (boss, 2026-10-07 and 2026-10-09)
- **Scope:** every UPRO and SCHG position, including hand-placed ones. Other assets, cash, deposits and withdrawals are excluded by construction.
- **Interval** = since the previous snapshot. It is not the calendar day.
- **Fees are signed and separate.** Real `/pnl` (2026-10-09, 238 positions): `unrealizedPnL.pnL` = `(closeRate − openRate) × units × closeConversionRate` within $0.005, so **pnL excludes fees**. `totalFees` is negative. `totalExternalFees` exists, non-zero on 2 positions. History realized = `netProfit + fees_signed`.
- **Market-explained part** (consultant formulas; `P0`/`P1` = the previous/current snapshot `closeRate`; `Be`/`Bx` = independent marks around the actual entry/exit; `q` = units):
  - held: `q×(P1−P0)`;
  - opened since: `q×(P1−Be)`;
  - closed since: `q×(Bx−P0)`;
  - round trip: `q×(Bx−Be)`.
  - The eToro fill price is never used as `Be`/`Bx`.
- **Three states:**
  - complete: compare to the thresholds;
  - incomplete/pending: loud, **no C**, never a threshold on a partial subtotal;
  - a proven integrity mismatch is stopped by gate 11 reconciliation, not here: this module reports it as incomplete with a reason.
- **Thresholds:** A at −$500 (`max_daily_loss_usd`), C at −$50.

## Design (PM decisions, revised after precheck 2026-10-09)
All amounts in USD (`accountCurrencyId` 1). Module contents:

1. **Data types**, all `@dataclass(frozen=True)`:
   - `PosObs(position_id: str, instrument_id: int, units: float, close_rate: float | None, pnl: float | None, fees: float, is_buy: bool, leverage: float)`. `fees` = `totalFees + totalExternalFees` as given (signed; a missing key counts as 0).
   - `ClosedLot(position_id: str, instrument_id: int, units: float, net_profit: float, fees: float, open_date: str | None, close_date: str | None)`. The caller maps it from `TradeHistoryEntry` (T022).
   - `IntervalResult(state: str, pnl_usd: float | None, pnl_pct: float | None, explained_usd: float | None, residual_usd: float | None, alert_a: bool, alert_c: bool, reasons: tuple[str, ...], lines: tuple[str, ...])`. `lines` holds one human line per counted position.
2. **States**, exactly four:
   - `no_baseline`;
   - `complete`;
   - `incomplete`: evidence missing → loud, no thresholds;
   - `integrity`: a proven mismatch. Units on the same position id changed. **Precheck: gate 11 does NOT detect this (`engine/reconcile.py:114–127` says the units invariant is not built), so this module flags it.** T022 stops trading on it (HALT).

   `integrity` overrides `incomplete`. Alerts A/C are only evaluated when `complete`.
3. **`observe(snap: PortfolioSnapshot, managed_ids: frozenset[int]) -> dict[str, PosObs]`**:
   - Read `snap.raw["pnl"]["clientPortfolio"]["positions"]`, keep `instrumentID in managed_ids`, and key by `str(positionID)`.
   - `close_rate`/`pnl` come from `unrealizedPnL.closeRate`/`.pnL`, else None.
   - A missing `raw["pnl"]` raises `ValueError("snapshot has no raw pnl")`.
4. **`compute_interval(prev: PortfolioSnapshot | None, cur: PortfolioSnapshot, *, managed_ids: frozenset[int], closed: Sequence[ClosedLot] | None, entry_marks: Mapping[str, float], exit_marks: Mapping[str, float], loss_alert_usd: float = 500.0, residual_halt_usd: float = 50.0) -> IntervalResult`**:
   - `prev is None`: return state `no_baseline`, all numbers None, alerts False, reasons `("no previous snapshot",)`.
   - `O0 = observe(prev, managed_ids)`, `O1 = observe(cur, managed_ids)`. `reasons: list[str] = []`, `incomplete = False`, `integrity = False`, `pnl_parts: list[float] = []`, `expl_parts: list[float] = []`.
   - `closed is None`: incomplete, reason `"trade history not supplied: closes and round trips unknown"`. Then treat `closed` as `()` for the rest.
   - If `prev.raw.get("complete") is not True` or `cur.raw.get("complete") is not True`: incomplete, reason `"snapshot marks incomplete"`.
   - Any position in `O0` or `O1` with `not is_buy` or `leverage != 1`: incomplete, reason `"position {id}: short or leveraged, not modelled"`, skip it.
   - **Held** (id in both, `p0`, `p1`):
     - `abs(p1.units − p0.units) > 1e-9`: `integrity = True`, reason `"position {id}: units changed {p0.units}->{p1.units}"`, skip.
     - Any of `p0.pnl`, `p1.pnl`, `p0.close_rate`, `p1.close_rate` is None: incomplete, reason `"position {id}: missing mark"`, skip.
     - Else append `pnl_c = (p1.pnl − p0.pnl) + (p1.fees − p0.fees)` and `expl = p1.units × (p1.close_rate − p0.close_rate)`.
   - **Opened since** (id in `O1` only, `p1`):
     - `p1.pnl` or `p1.close_rate` is None: incomplete, reason `"position {id}: missing mark"`, skip.
     - Else append `pnl_c = p1.pnl + p1.fees`.
     - Entry mark `Be = entry_marks.get(id)`. If None: incomplete, reason `"position {id}: opened since, no independent entry mark"` (`pnl_c` stays counted). Else append `expl = p1.units × (p1.close_rate − Be)`.
   - **Closed since** (id in `O0` only, `p0`):
     - Find `lot` in `closed` with `lot.position_id == id`. If none: incomplete, reason `"position {id}: closed since, realized P&L pending in history"`, skip.
     - `p0.pnl` or `p0.close_rate` is None: incomplete, reason `"position {id}: missing mark"`, skip.
     - Else append `pnl_c = (lot.net_profit + lot.fees) − (p0.pnl + p0.fees)`.
     - Exit mark `Bx = exit_marks.get(id)`. If None: incomplete, reason `"position {id}: closed since, no independent exit mark"` (`pnl_c` stays counted). Else append `expl = lot.units × (Bx − p0.close_rate)`.
   - **Round trip:** a lot in `closed` with `position_id` in neither `O0` nor `O1`, `instrument_id in managed_ids`, `open_date` not None, and `_utc(open_date) > _utc(prev.taken_at)`. Helper `_utc(s) = datetime.fromisoformat(s.replace("Z", "+00:00"))`, and a naive result is treated as UTC.
     - Append `pnl_c = lot.net_profit + lot.fees`.
     - Both `Be = entry_marks.get(id)` and `Bx = exit_marks.get(id)` are needed. If either is missing: incomplete, reason `"position {id}: round trip, missing independent mark"`. Else append `expl = lot.units × (Bx − Be)`.
   - Other lots in `closed` are ignored.
   - `pnl_usd = sum(pnl_parts)` (0.0 when empty).
   - `state = "integrity" if integrity else "incomplete" if incomplete else "complete"`.
   - If `state == "complete"`: `explained_usd = sum(expl_parts)`, `residual_usd = pnl_usd − explained_usd`. Else both None.
   - `pnl_pct`: `base = Σ over ids in O0 (not skipped as short/leveraged) of (prev SnapshotPosition.amount + p0.pnl)`, matching `prev.positions` by `position_id`. If any row has a None amount or pnl, `pnl_pct` = None. `pnl_pct = 100 × pnl_usd / base` if `base > 0`, else None.
   - `alert_a = state == "complete" and pnl_usd <= −loss_alert_usd`.
   - `alert_c = state == "complete" and residual_usd <= −residual_halt_usd`.
   - `lines`: one per counted position, `f"{id} {kind}: pnl {pnl_c:+.2f}, market {expl:+.2f}"` (market shown as `n/a` when no expl). Returned floats are unrounded.
5. **Why this shape:**
   - Pure inputs give deterministic tests.
   - Marks and history are injected, so S7 can supply real `Be`/`Bx` later.
   - The units integrity check lives here because gate 11 lacks it.
   - A partial subtotal is never thresholded.
