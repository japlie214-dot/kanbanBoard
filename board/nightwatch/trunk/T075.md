# Missed-session alert, heartbeat and command parity

The Boss is told when a scheduled session did not run, and every Telegram/Worker command the bot advertises works on the phone.

## Scope

AlarmScheduler.kt, AndroidManifest.xml, CommandHandler.kt, cloud/worker, tests.

Deliver: heartbeat from the Worker side or next-day check, PACKAGE_REPLACED/TIME_SET reschedule, command parity.
