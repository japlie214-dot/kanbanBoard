## Advisory Notes (P2)
1. `viewer.py` GET routes `/api/doc/export/html`, `/api/doc/export/print-html`, `/api/doc/export/pdf`, `/api/doc/manifest`, and `/api/version/history` do not wrap `ValueError` from invalid `project` slugs into HTTP `400` (unlike `/api/doc/snapshots` which explicitly catches `ValueError` -> `400`); `_validate_project` still blocks path traversal before disk access.
2. `kb_doc_export.build_offline_html` intentionally embeds `<style>` (`inline_css=True`) for standalone downloaded HTML (`download="..."` attribute in `doc_shared/shell.js`); if opened directly inline from `viewer.py` rather than downloaded, `style-src 'self'` blocks inline `<style>` (unlike `/api/doc/export/print-html`, which uses `/api/doc/export/print.css`).
3. `kb_doc_queue.start_background_worker` mutates `_WORKER_THREAD`/`_WORKER_BOARD` outside `_GLOBAL_LOCK`; low risk under single-threaded startup, but a dedicated lifecycle lock would harden concurrent multi-caller initialization.
4. Note: `kanban_board(view="lint")` reported pre-existing `_cases/: missing project.md` and `_cases/attachments/: missing epic.md` unrelated to `T012` scope (`pre_commit_verify_done.py` returned `verify-done: OK`).
